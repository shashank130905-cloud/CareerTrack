# CareerTrack Test Cases

The accompanying `Test_Cases.xlsx` provides the required test-case fields. All actual results are marked **Not Run** initially. Execute each case against the running system and record evidence before claiming a pass.

Coverage: public job browsing/search/filter/detail; guest application; résumé type/size validation; duplicate prevention; expired/closed job rejection; admin login; protected API access; job create/update/publish/close; application status and notes; CSV export; invalid identifiers and server errors; mobile responsiveness.
